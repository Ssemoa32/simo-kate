## المميزات

- تعابير متحركة لحالات الخمول والاستماع والتفكير والكلام والسعادة والنوم.
- إدخال صوتي باستخدام Web Speech API في المتصفحات المدعومة.
- اتصال بمساعد ذكي عبر خادم متوافق أو مزوّد API.
- قائمة مهام تُحفظ محليًا في المتصفح.
- وجه تفاعلي مرسوم على Canvas مع نجوم وتأثيرات بصرية.
- تصميم متجاوب للهواتف والشاشات الكبيرة.

## التشغيل

افتح `index.html` في متصفح حديث، أو شغّل خادمًا محليًا من مجلد التطبيق:

```bash
python -m http.server 8000
```

ثم افتح `http://localhost:8000`. قد تتطلب ميزات الصوت وطلبات الشبكة اتصالًا آمنًا (`HTTPS` أو `localhost`).

## الاتصال بالذكاء الاصطناعي

يدعم التطبيق الاتصال بخادم خلفي عبر `POST /api/chat`، كما يدعم الاتصال المباشر بمزوّد API. يتوقع التطبيق استجابة JSON تحتوي على `reply`، ويمكن أن تتضمن `mood` و`intensity` و`duration`.

> **تنبيه أمني:** لا تضع مفاتيح API السرية في واجهة المتصفح؛ فالمفاتيح المخزنة في المتصفح يمكن للمستخدمين الاطلاع عليها. استخدم خادمًا خلفيًا لحماية الأسرار.
