# Simo و Kate

رفيقان روبوتان لطيفان تتكلم معهما بصوتك وتظهر مشاعرهما في العيون

Made with [CodeAgent Remix](https://www.codeagent-mobile.com/remix). Live app: https://simo-kate-guev8efz.remixapps.app/

## Run it locally

A Vite + TypeScript project. You need Node.js 20 or newer.

```bash
npm install
npm run dev
```

Build it with `npm run build`.
